PRIVACY

Privacy choices

Parajuli Cosmetic Centre's website uses visitor analytics only with consent. The current GitHub Pages implementation does not collect or transmit raw IP addresses or exact GPS coordinates.

Location

If you choose the location option, your browser provides location data so the page can calculate your approximate distance from the store. The current implementation does not send those coordinates to the site owner.

Analytics

With consent, the page records only a local session marker containing the page, language, approximate device category and visit time. It is not a hidden tracking system.

Your choice

You can decline analytics and deny browser location permission. Browser location permission can also be changed through your browser settings.
